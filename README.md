
# ChildMind RAG

아동 발달·양육 관련 공개 문헌을 활용해
문서 수집부터 검색, 답변 생성, 평가까지 직접 구현하는 학습 프로젝트.

## 목표

- PDF에서 텍스트와 출처 정보를 추출한다.
- Dense Retrieval 기반 RAG를 구현한다.
- BM25와 RRF를 추가하고 검색 성능을 비교한다.
- FastAPI로 질문·답변 API를 제공한다.
